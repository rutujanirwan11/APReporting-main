## Description

The Commercial Rent Roll report is a version of the standard Rent Roll that is specifically geared towards commercial properties. This report gives you a high-level overview of the rent and transactional impact for all suites and tenants within the property as well as an Occupancy Summary breakdown for each building within the property. Currently, only clients that have access to the Commercial product can use this report.
