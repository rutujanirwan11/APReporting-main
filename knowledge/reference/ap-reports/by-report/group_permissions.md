## Description

This report allows you to audit group permissions and access levels, (read only, deny, and allow).
Note: There are over 2,500 permissions available in the system, which is a lot of data when running it for all groups. Below are some tips and tricks to running this report.
1. We suggest that you do not run this report by generating it in the Entrata System. Instead, we ask that you download it as an XLS, PDF, or CSV. 
2. Because of the large amount of data, we do not allow you to consolidate all groups onto one page. This helps increase the report generation time and decreases the chance of the browser crashing.
3. When running this report in the E and selecting all groups, your browser may crash. To avoid that see item #1.
