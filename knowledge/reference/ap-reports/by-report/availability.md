## Description

This report provides a listing of units that are currently available to be leased to potential residents. This report should be beneficial to leasing agents (on a daily basis) to allow them to identify available units when meeting with leads or existing households looking to transfer. Currently, all clients (core and integrated) can use this report. For larger texts on PDF downloads please remove disabled columns.
