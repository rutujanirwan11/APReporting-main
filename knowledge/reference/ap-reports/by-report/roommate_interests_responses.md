## Description

The Roommate Interests Responses report will provide you with a viewable/printable list of all active residents and leads and their application preference questions and responses that would be used for roommate matching purposes. This is a useful report for any student properties in conjunction with Bulk Unit Assignments (BUA) and matching students with similar preferences. Currently, only clients that have Entrata Core and Student can use this report.
