## Description

The CallAnalysis Results report will give an overview of the call results from call analysis. It will shows what the Leasing Center graders finished, evaluated and analyzed. (This report is only looking at Call Analysis calls and will not tie out to other call tracker reports.) Must have CallAnalysis to run this report. This report only considers Lead calls
