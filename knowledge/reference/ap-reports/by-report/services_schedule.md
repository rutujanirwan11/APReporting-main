## Description

The purpose of this report is to support updates to the Services product which, when setup by the property, allows residents to schedule certain services. This report provides both a summary and details pertaining to these scheduled services and helps the property operators track them. For services which the property choose to track completion on, this report will help track which have been completed and which remain incomplete.
