## Description

The Revenue Performance Analysis report shows an overall view of how a specific property is performing regarding pricing. The performance numbers are broken up between new leases, renewal leases, and an executive analysis. This report gives values such as rent per executed sqft and average vacant days to help guide pricing decisions. Please Note: This report requires your company to use Revenue Management product to be able to access this report.
