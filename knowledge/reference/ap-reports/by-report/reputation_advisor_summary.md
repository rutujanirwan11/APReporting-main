## Description

The <strong>Reputation Advisor Summary</strong> report provides a high-level overview of reviews and ratings received in a given period.  This includes counts and percentages of overall reviews, ratings, and recommendations.  The metrics in this report are designed to match the Reputation Dashboard (Tools >> Reputation >> Dashboard) when run for the same properties, period, and sources.
