## Description

The Application Progress Summary Report will track how well leads are progressing through the application process and will help you to identify whether the progress is made in-office or online. The report bases its metrics on the number of started applications. This means that Started Applications will equal Abandoned Applications plus Lost Applications plus Completed Applications.No product requirements are necessary to use this report.
