## Description

The Payment Adoption By Type report will allow you to measure the adoption of paperless payments for your property(ies).You will be able to see a unit, lease and transaction count, as well as a percentage breakdown in this report.This information will better help you compare numbers for each payment type and allow you to see how many of your residents are paying using paperless payment options. The Payment Adoption report does not include data for payments made via Prospect Portal, i.e application payments, admin fees, ect.
