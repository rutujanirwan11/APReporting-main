## Description

This report provides you with high-level information concerning various key resident portal traffic data points. This report will provide information pertaining to leases, emails, resident enrolled in Resident Portal, work orders, different payment types, etc. for all units within selected properties. Currently, all clients (core and integrated) can use this report.
